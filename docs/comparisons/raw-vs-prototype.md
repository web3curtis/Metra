# Raw WebMCP versus Metra prototype

Generated by `tests/rawVsPrototype.test.ts`. Both lanes register the same 24 tools on the same
`document.modelContext` surface and receive an identical call sequence. The only difference is
whether the A–D2 enforcement boundary sits in front of the handlers.

Two things are measured: how many effects each lane actually produced, and whether the
agent was told about an effect the store does not hold.

| S4 The site's handler reports a success it never performed | 0 | 0 | 0 | **false report** | correct |
